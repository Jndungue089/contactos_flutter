# Contactos Flutter

App **Flutter** de cadastro de pessoas com **foto**, guardando os dados no **Back4App** (Parse Server).

- Formulário de cadastro com seleção de imagem da galeria (`image_picker`).
- Persistência na nuvem através de `parse_server_sdk_flutter`.

## Executar

1. Crie uma app no [Back4App](https://www.back4app.com) e atualize as chaves `keyApplicationId` e `keyClientKey` em `lib/main.dart`.
2. Corra:

```bash
flutter pub get
flutter run
```
